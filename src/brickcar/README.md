# brickcar：混合车 3D → 用真实零件搭出来的乐高车

输入是 `python -m hybrid compose` 的输出文件夹，输出是一个能导入 BrickLink Studio / LDView / LeoCAD 的 LDraw 模型（`model.ldr`），以及零件清单。

目标是**看起来像人搭的**，不是长方体体素堆出来的：真实轮子装在 Technic 轴上，车身顶面用 tile、曲面斜坡、cheese 斜坡收成无凸点的表面，玻璃区域用真实的挡风玻璃零件，车灯和格栅用 SNOT（侧面带凸点的砖）侧装。

## 用法

```bash
python -m brickcar build outputs/hybrid/veyron_fordgt_tacoma [--width-studs 14]
```

输出在 `outputs/brickcar/<name>_w<宽度>/`：`model.ldr`、`bom.csv`（零件清单，包括颜色和数量）、`views.jpg`、`compare.jpg`（混合车和乐高版用同一组相机对比）、`turntable.gif`、`info.json`。

比例由车宽决定：默认 14 stud 宽，约 1:17，1 stud ≈ 13.7 cm。可以改成 12 或 16。

## 流程（`build.py`）

| 步骤 | 做法 |
|---|---|
| 目标 | 把混合车的 SDF 采样到乐高网格（stud × stud × plate），每个 stud 再分 4×4 个子采样，得到每一列的顶面高度、底面高度、颜色，并左右对称化（`target.py`） |
| 轮子 | 按轮胎直径和宽度选一个完整轮子（轮毂和轮胎一体），优先街车胎；装在 Technic 轴上，轴穿过 Technic brick 1×4 with holes。孔离砖底 14 LDU，所以孔的高度决定支架在哪一层。轮拱按圆弧逐列挖成阶梯状 |
| 顶面 | 对每个"零件 × 4 个朝向 × 位置"，比较零件的顶面高度图和目标表面，给出误差、零件数代价和凸点惩罚。按代价从低到高贪心放置，每次连同镜像一起放。挡风玻璃零件只在玻璃区域（顶面颜色深且在腰线以上）有奖励 |
| 细节 | 车头前表面放 SNOT 砖（87087），侧面装透明圆 tile 作大灯、1×2 格栅 tile 作格栅；车尾装透明红圆 tile 作尾灯 |
| 车身 | 每一列从车底（或轮拱顶）填到顶面零件的底部，一层一层放：大砖只能放在共同的砖层上，能放下的最大零件优先，跨接下层两个零件的放法加分（错缝），各层方向交替 |
| 颜色 | 看得见的零件取它所在位置混合车表面的颜色，量化到乐高色板；深色且在腰线以上的改成透明黑（玻璃）；看不见的用浅灰 |
| 检查 | 用 BrickNet 的连接推断（凸点、轴、孔）计算连通分量，去掉少于 5 个零件、没连到车身的碎片 |

零件的朝向和尺寸不靠手写，全部从零件网格（BrickNet GLB）自动测量（`parts.py`）：包围盒、占地面积、顶面高度图、4 个朝向，以及哪个朝向是镜像。

## 已知局限和下一步

- 车身侧面是竖直的砖墙，有阶梯。下一步可以用 SNOT + tile 把侧面做平，或者在侧面加曲面斜坡。
- 很陡的挡风玻璃（皮卡驾驶室）找不到合适的玻璃零件，仍然是透明黑的台阶。
- 车尾的细碎曲面（比如威龙的发动机盖）会用到很多小 cheese 斜坡，看起来比较乱。
- 轮拱是矩形阶梯，还没用拱形砖或挡泥板零件。
- 内部是实心的，零件数偏多。可以做成空心车身加内部支撑。
- 连通性只按"连在一起"检查，没有做受力或稳定性分析。
